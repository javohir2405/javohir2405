## 1. Mashg'ulot maqsadi va xesh funksiyalarni tajribada sinash

Bu fanning yakuniy amaliy mashg'uloti bo'lib, unda talabalar xesh jadvallarni dasturlaydilar va butun kurs davomida o'rganilgan tuzilmalar hamda algoritmlarni birlashtirib, «Kutubxona axborot tizimi» yakuniy loyihasini bajaradilar. Mashg'ulot ikki qismdan iborat. Birinchi qismda xesh funksiyalar, to'qnashuvlar va xesh jadvalning ishlashi tajribada o'rganiladi. Ikkinchi qismda katalog, buyurtmalar navbati, qidirish va saralash imkoniyatlarini o'z ichiga olgan dastur yaratiladi.

Mashg'ulot oldingi mavzuni takrorlashdan boshlanadi. O'qituvchi talabalarga savollar beradi: xesh funksiya nima, to'qnashuv nima uchun yuz beradi, zanjirlash va ochiq adreslash usullarining farqi nimada, yuklanish koeffitsienti nimani bildiradi. Talabalar o'z javoblarini beradilar. Shundan keyin o'qituvchi kutilgan natijalarni e'lon qiladi: talaba xesh funksiya yoza oladi, to'qnashuvlarni sanay oladi, xesh jadvalni dasturlay oladi va uni boshqa tuzilmalar bilan taqqoslay oladi.

Birinchi topshiriq — xesh funksiyalar sifatini taqqoslash. Talabalar uchta oddiy xesh funksiya yozadilar. Birinchisi satrdagi belgilar kodlari yig'indisini jadval o'lchamiga bo'ladi. Ikkinchisi polinomial xesh bo'lib, asos 31 dan foydalanadi. Uchinchisi satrning faqat birinchi harfi kodini oladi. Har bir funksiya uchun 1000 ta kitob nomi bir xil o'lchamli jadvalga taqsimlanadi va to'qnashuvlar soni hamda eng uzun chelak uzunligi hisoblanadi. Natijada birinchi harfga asoslangan funksiya juda yomon, polinomial xesh esa eng yaxshi ekani ko'rinadi.

```python
import random, string

def yigindi_xesh(s, m):
    return sum(ord(c) for c in s) % m

def polinomial_xesh(s, m):
    h = 0
    for c in s:
        h = (h * 31 + ord(c)) % m
    return h

def birinchi_harf_xesh(s, m):
    return ord(s[0]) % m

random.seed(7)
nomlar = ["".join(random.choices(string.ascii_lowercase, k=random.randint(5, 12)))
          for _ in range(1000)]
m = 211
for f in (yigindi_xesh, polinomial_xesh, birinchi_harf_xesh):
    chelaklar = [0] * m
    for nom in nomlar:
        chelaklar[f(nom, m)] += 1
    bosh = sum(1 for c in chelaklar if c == 0)
    print(f.__name__, "eng uzun chelak:", max(chelaklar), "bo'sh chelaklar:", bosh)
```

Natijalarni tahlil qilishda talabalar ideal taqsimot bilan solishtirish uchun o'rtacha chelak uzunligini hisoblaydilar: 1000 / 211 taxminan 4,7. Yaxshi xesh funksiyada eng uzun chelak bu qiymatdan 3–4 barobar ortiq bo'lmaydi va bo'sh chelaklar kam bo'ladi. Birinchi harfga asoslangan funksiyada esa kalitlar faqat 26 ga yaqin chelakka tushadi, ko'pchilik chelaklar bo'sh qoladi. Bu tajriba yaxshi xesh funksiya nima uchun tekis taqsimlashi kerakligini aniq ko'rsatadi.

Ikkinchi topshiriq — to'qnashuvlar sonini jadval o'lchamiga bog'liq holda o'rganish. Talabalar 100 ta kalitni o'lchami 101, 211, 503 va 1009 bo'lgan jadvallarga taqsimlaydilar va to'qnashuvlar sonini hisoblaydilar. Tub son o'lchamlar ishlatiladi. Shuningdek, juft va ikki darajasi bo'lgan o'lchamlarda, masalan, 128 va 256 da, yig'indi xesh qanday natija berishini ham tekshiradilar. Ular tub son o'lchamlar kalitlardagi qonuniyatlarni yaxshiroq yo'q qilishini tajribada ko'radilar. Natijalar jadvalga yoziladi.

Mashg'ulotning yakuniy xarakterini hisobga olib, talabalarga butun kursni qisqacha takrorlash imkoniyati ham beriladi. Har bir guruh bitta mavzu, masalan, massivlar, ro'yxatlar, stek va navbat, rekursiya, daraxtlar yoki graflar bo'yicha uch daqiqalik qisqacha taqdimot tayyorlaydi. Taqdimotda tuzilmaning g'oyasi, asosiy amallari, murakkabligi va kutubxonadagi qo'llanishi ko'rsatiladi. Bu takrorlash talabalarga butun fanni yagona tizim sifatida ko'rish imkonini beradi va loyihani bajarishdan oldin kerakli bilimlarni faollashtiradi.

## 2. Xesh jadvalni zanjirlash usulida dasturlash

Ikkinchi bosqichda talabalar zanjirlash usulidagi xesh jadvalni o'zlari yozadilar. Nazariy darsdagi namuna asos qilib olinadi, lekin talabalar uni mustaqil yozishlari, kerakli o'zgartirishlarni kiritishlari shart. Sinfda quyidagi metodlar bo'ladi: qo'shish, qidirish, o'chirish, yuklanish koeffitsientini hisoblash, jadvalni qayta xeshlash va chelaklar uzunliklari statistikasini chiqarish. Qayta xeshlash yuklanish koeffitsienti 0,75 dan oshganda avtomatik bajariladi va jadval o'lchami ikki barobar oshiriladi.

```python
class Xesh:
    def __init__(self, m=8):
        self.m = m
        self.chelak = [[] for _ in range(m)]
        self.soni = 0
        self.qayta_xeshlash_soni = 0

    def yuklanish(self):
        return self.soni / self.m

    def _ind(self, kalit):
        return hash(kalit) % self.m

    def _kengaytir(self):
        eski = self.chelak
        self.m *= 2
        self.chelak = [[] for _ in range(self.m)]
        for ch in eski:
            for k, v in ch:
                self.chelak[self._ind(k)].append((k, v))
        self.qayta_xeshlash_soni += 1

    def qosh(self, kalit, qiymat):
        ch = self.chelak[self._ind(kalit)]
        for i, (k, _) in enumerate(ch):
            if k == kalit:
                ch[i] = (kalit, qiymat)
                return
        ch.append((kalit, qiymat))
        self.soni += 1
        if self.yuklanish() > 0.75:
            self._kengaytir()

    def ol(self, kalit, standart=None):
        for k, v in self.chelak[self._ind(kalit)]:
            if k == kalit:
                return v
        return standart

    def ochir(self, kalit):
        ch = self.chelak[self._ind(kalit)]
        for i, (k, _) in enumerate(ch):
            if k == kalit:
                ch.pop(i)
                self.soni -= 1
                return True
        return False

x = Xesh()
for i in range(100):
    x.qosh(f"kitob{i}", i)
print(x.soni, x.m, x.qayta_xeshlash_soni, round(x.yuklanish(), 2))
print(x.ol("kitob42"), x.ol("yo'q", "topilmadi"), x.ochir("kitob42"), x.ol("kitob42"))
```

Dastur ishga tushirilganda talabalar jadval o'lchami 8 dan 256 gacha ikki barobardan oshganini va yuklanish koeffitsienti hech qachon 0,75 dan oshmaganini ko'radilar. Qayta xeshlash soni logarifmik, ya'ni 100 ta element uchun besh marta bajarilgan. Bu amortizatsiyalangan tahlilni tasdiqlaydi: kamdan-kam qimmat amal bajarilgani uchun o'rtacha qo'shish tezligi doimiy bo'lib qoladi. Talabalar qayta xeshlash chegarasini 0,5 va 0,9 ga o'zgartirib, jadval o'lchami va qayta xeshlash soni qanday o'zgarishini taqqoslaydilar.

Sinov uchun avtomatik tekshiruv yoziladi. Tasodifiy qo'shish, yangilash va o'chirish ketma-ketligi ham xesh jadvalda, ham Python lug'atida bajariladi. Har bir qadamdan keyin ikkalasining tarkibi bir xil ekani tekshiriladi. Shu usulda xesh jadvalning to'g'riligi ishonchli tasdiqlanadi. Xato topilsa, uni ajratib olish uchun operatsiyalar ketma-ketligi chiqariladi. Talabalar bu usulni oldingi mashg'ulotlarda ham qo'llaganlar va endi uni mustaqil ravishda xesh jadvalga tatbiq etadilar.

Uchinchi topshiriq — xesh jadvalni boshqa tuzilmalar bilan tezlik bo'yicha taqqoslash. Talabalar 100 000 ta butun sondan iborat to'plam yaratadilar va ro'yxat, tartiblangan ro'yxat (binar qidirish bilan), ikkilik qidiruv daraxti va xesh jadvalda 10 000 ta tasodifiy qidirishning vaqtini o'lchaydilar. Natijalar jadvalga yoziladi. Odatda eng tez xesh jadval, keyin binar qidirish va daraxt, eng sekin esa oddiy ro'yxat bo'ladi. Bu tajriba butun kurs davomida o'rganilgan qidirish usullarini bir joyda taqqoslash imkonini beradi va talabalarga umumiy tasavvur beradi.

To'rtinchi topshiriq — xesh jadval yordamida so'zlar chastotasini hisoblash va anagrammalarni guruhlash. Berilgan matndagi har bir so'z necha marta uchrashi lug'atda sanaladi, natija kamayish tartibida chiqariladi. Anagrammalarni guruhlash uchun har bir so'zning harflari saralanadi va saralangan satr kalit sifatida ishlatiladi: bir xil harflardan tuzilgan so'zlar bir kalitga tushadi. Natijada anagrammalar guruhlari hosil bo'ladi. Bu masalalar xeshlash g'oyasining samaradorligini ko'rsatadi, chunki ular O(n) vaqtda yechiladi, ichma-ich sikl esa O(n²) bo'lardi.

Xesh jadvalni sinashda talabalar yana bir muhim holatni tekshiradilar: bir xil kalitni ikki marta qo'shish. Natijada jadvalda faqat bitta yozuv qolishi, qiymat esa yangilanishi kerak, elementlar soni esa o'zgarmasligi lozim. Dasturda shu holat noto'g'ri ishlansa, takroriy yozuvlar paydo bo'ladi va qidirish natijasi noaniq bo'ladi. Talabalar bunday sinovni avtomatik testga qo'shadilar. Shuningdek, bo'sh jadvalda qidirish va o'chirish, mavjud bo'lmagan kalitni qidirish kabi holatlar ham sinaladi va xatosiz ishlashi tekshiriladi.

Xesh jadvalni umumiylashtirish uchun talabalar ixtiyoriy turdagi kalitlarni qo'llab-quvvatlashini ham sinab ko'radilar. Satrlar, butun sonlar va kortejlar jadvalga kalit sifatida qo'shiladi va Python ularning xesh qiymatini hash funksiyasi bilan hisoblaydi. Ro'yxat kalit sifatida berilsa, xato yuz berishi ko'riladi, chunki ro'yxat o'zgaruvchan. Talabalar o'zlarining sinflari uchun xesh va tenglik metodlarini aniqlashni ham o'rganadilar: __hash__ va __eq__ metodlari ikki obyekt teng bo'lsa, ularning xesh qiymatlari ham teng bo'lishini ta'minlashi kerak. Bu qoida buzilsa, jadval noto'g'ri ishlaydi.

## 3. Ochiq adreslash va to'qnashuvlarni tahlil qilish

Uchinchi bosqichda talabalar ochiq adreslash usulini chiziqli probalash bilan dasturlaydilar. Jadval massivi va uni band, bo'sh va o'chirilgan kataklarini belgilovchi maxsus qiymatlar tayyorlanadi. Qo'shish, qidirish va o'chirish amallari proba ketma-ketligi bo'yicha bajariladi. O'chirish uchun «qabr toshi» usuli qo'llanadi. Talabalar jadvalda har bir amalda necha marta proba qilinganini sanaydilar, shuning uchun yuklanish koeffitsienti ortgan sari probalar soni qanday o'sishini kuzata oladilar.

Tajriba quyidagicha o'tkaziladi. O'lchami 1009 bo'lgan jadvalga tasodifiy kalitlar birin-ketin qo'shiladi. Har 100 ta qo'shishdan keyin yuklanish koeffitsienti va oxirgi 100 ta qo'shishdagi o'rtacha probalar soni yoziladi. Natijada yuklanish 0,5 gacha o'rtacha probalar soni 1,5 dan oshmaydi, 0,8 da 3 dan oshadi, 0,95 da esa o'nlab probaga yetadi. Talabalar bu qiymatlarni nazariy formulalar bilan solishtiradilar va jadval 70 foizdan ko'p to'ldirilmasligi nima uchun tavsiya etilishini o'zlari tushuntiradilar.

Keyin chiziqli, kvadratik probalash va ikki marta xeshlashni taqqoslash o'tkaziladi. Uchala usul uchun bir xil kalitlar to'plami bilan tajriba takrorlanadi. Chiziqli probalashda birlamchi to'planish tufayli uzun band bloklar hosil bo'lishi, kvadratik probalashda to'planish kamayishi, ikki marta xeshlashda eng kam probalar soni kuzatilishi kutiladi. Talabalar natijalarni grafik yoki jadval ko'rinishida taqdim etadilar. Agar natija kutilganidan farq qilsa, sabablarini muhokama qiladilar: xesh funksiya sifati, jadval o'lchami, kalitlar xususiyati.

Mashg'ulotning bu qismida o'chirishning nozik tomonlari ham sinaladi. Talabalar ataylab uch kalit olib, ularni bir xil indeksga tushadigan qilib tanlaydilar, uchalasini ketma-ket qo'shadilar, o'rtadagisini o'chiradilar va oxirgisini qidirib ko'radilar. Agar o'chirish «qabr toshi»siz amalga oshirilgan bo'lsa, oxirgi kalit topilmay qoladi. Bu xatoni o'z ko'zlari bilan ko'rgan talabalar o'chirilgan katak belgisining zarurligini yaxshi tushunadilar. Shu bilan ochiq adreslashdagi eng ko'p uchraydigan xato bartaraf etiladi.

Python lug'atining ichki tuzilishi haqida qisqa tajriba o'tkaziladi. sys.getsizeof funksiyasi yordamida lug'at hajmi elementlar qo'shilganda qanday oshishi kuzatiladi. Hajm uzluksiz emas, sakrashlar bilan o'sadi, bu qayta xeshlashni anglatadi. Talabalar lug'atga 1, 2, 3, ... elementlar qo'shib, hajm o'zgargan nuqtalarni aniqlaydilar. Bu tajriba tayyor tuzilma ichida o'zlari yozgan jadvalga o'xshash mexanizm ishlayotganini ko'rsatadi va nazariyani real texnologiyalar bilan bog'laydi.

Mashg'ulotning shu qismida talabalar xesh jadvalning real hayotdagi samaradorligini ko'rsatadigan yana bir tajriba o'tkazadilar. Ular millionta so'zdan iborat matn yaratadilar va unda takrorlanuvchi so'zlarni topadilar. Birinchi usulda ro'yxat ichida chiziqli qidirish ishlatiladi, ikkinchi usulda to'plam. Birinchi usul bir necha soat, ikkinchisi esa soniyalar olishi mumkin, shuning uchun talabalar tajribani kichikroq hajmda, masalan, o'n ming so'z bilan boshlab, vaqt o'sishini kuzatadilar va katta hajm uchun taxmin qiladilar. Bu nazariy murakkablikning amaliy ma'nosini yaqqol ko'rsatadi.

## 4. Yakuniy loyiha: Kutubxona axborot tizimi

Mashg'ulotning asosiy qismi — butun kurs bilimlarini birlashtiruvchi yakuniy loyiha. Talabalar guruhlarda «Kutubxona axborot tizimi» dasturini ishlab chiqadilar. Dastur matnli menyu orqali ishlaydi va quyidagi imkoniyatlarga ega bo'lishi kerak: kitob yozuvlarini qo'shish va o'chirish; ISBN bo'yicha kitobni tezkor topish; muallif bo'yicha alifbo tartibida qidirish; kitoblarni nom, muallif yoki yil bo'yicha saralash; buyurtmalar navbati; qaytarilgan kitoblar uchun stek; kalit so'z bo'yicha qidirish. Har bir imkoniyat uchun mos ma'lumotlar tuzilmasi tanlanadi.

Tuzilmalar tanlovi quyidagicha tavsiya etiladi. ISBN bo'yicha tezkor qidirish uchun lug'at, ya'ni xesh jadval ishlatiladi: kalit ISBN, qiymat kitob yozuvi. Kalit so'z bo'yicha qidirish uchun inversiyalangan indeks quriladi: kalit so'z, qiymat shu so'z uchragan ISBN to'plami. Muallif bo'yicha tartiblangan qidirish uchun ikkilik qidiruv daraxti yoki tartiblangan ro'yxat va binar qidirish ishlatiladi. Buyurtmalar uchun navbat, qaytarilgan kitoblar uchun stek, saralash uchun o'rganilgan algoritmlar yoki sorted funksiyasi qo'llaniladi.

```python
from collections import deque

class Kitob:
    def __init__(self, isbn, nom, muallif, yil):
        self.isbn, self.nom, self.muallif, self.yil = isbn, nom, muallif, yil

    def __repr__(self):
        return f"{self.muallif}: {self.nom} ({self.yil})"

class KutubxonaTizimi:
    def __init__(self):
        self.kitoblar = {}                 # ISBN -> Kitob (xesh jadval)
        self.indeks = {}                   # so'z -> ISBN to'plami
        self.buyurtmalar = {}              # ISBN -> navbat
        self.aravacha = []                 # qaytarilgan kitoblar steki

    def qosh(self, kitob):
        self.kitoblar[kitob.isbn] = kitob
        for soz in kitob.nom.lower().split():
            self.indeks.setdefault(soz, set()).add(kitob.isbn)

    def isbn_boyicha(self, isbn):
        return self.kitoblar.get(isbn)

    def soz_boyicha(self, soz):
        return [self.kitoblar[i] for i in self.indeks.get(soz.lower(), ())]

    def saralash(self, mezon):
        return sorted(self.kitoblar.values(), key=lambda k: getattr(k, mezon))

    def buyurtma_ber(self, isbn, oquvchi):
        self.buyurtmalar.setdefault(isbn, deque()).append(oquvchi)

    def kitob_qaytar(self, isbn):
        self.aravacha.append(isbn)
        navbat = self.buyurtmalar.get(isbn)
        return navbat.popleft() if navbat else None

t = KutubxonaTizimi()
t.qosh(Kitob("111", "O'tkan kunlar", "Qodiriy", 1925))
t.qosh(Kitob("222", "Xamsa", "Navoiy", 1485))
t.qosh(Kitob("333", "Kecha va kunduz", "Cho'lpon", 1936))
t.buyurtma_ber("111", "Aziza"); t.buyurtma_ber("111", "Bobur")
print(t.isbn_boyicha("222"), t.soz_boyicha("kunduz"))
print(t.saralash("yil"))
print(t.kitob_qaytar("111"), t.kitob_qaytar("111"), t.kitob_qaytar("111"))
```

Loyihani bajarishda talabalar quyidagi bosqichlardan o'tadilar. Birinchi bosqich — talablarni aniqlash va tuzilmalarni tanlash, bunda jamoa har bir imkoniyat uchun qaysi tuzilma ishlatilishini asoslaydi. Ikkinchi bosqich — dasturni loyihalash: sinflar va funksiyalar tuzilishi qog'ozda chiziladi. Uchinchi bosqich — kod yozish, bunda har bir a'zo o'z qismini bajaradi. To'rtinchi bosqich — sinash, bunda har bir funksiya uchun avtomatik sinovlar yoziladi. Beshinchi bosqich — taqdimot, bunda guruh o'z yechimini himoya qiladi. Bu bosqichlar real loyihalarning rivojlanish davriga mos keladi.

Loyiha himoyasida talabalar quyidagi savollarga javob berishlari kerak. Nima uchun aynan shu tuzilmalar tanlandi? Har bir asosiy amalning murakkabligi qancha? Katalogda million kitob bo'lsa, tizim qanday ishlaydi, qaysi qismi to'siq bo'ladi? Tizimni qanday yaxshilash mumkin? Masalan, ISBN bo'yicha qidirish xesh jadval tufayli O(1), saralash O(n log n), kalit so'z bo'yicha qidirish indeks tufayli indeks hajmiga qarab tez. Yaxshilash yo'llari: ma'lumotlarni faylga saqlash, muallif bo'yicha daraxt indeksi qo'shish, ustuvorlik navbati joriy etish.

Loyiha baholanayotganda quyidagi mezonlar hisobga olinadi: tuzilmalarni to'g'ri va asosli tanlash, funksiyalarning to'g'ri ishlashi, kod tozaligi va izohlar, sinovlar mavjudligi, murakkablik tahlili sifati, taqdimot va savollarga javoblar, jamoadagi hissa. Har bir mezon bo'yicha ball qo'yiladi va umumiy baho shakllanadi. Eng yaxshi loyihalar kutubxonada o'quv namunalari sifatida saqlanishi va keyingi o'quv yillarida foydalanilishi mumkin. Bu talabalar uchun qo'shimcha rag'bat bo'ladi.

Mashg'ulot va butun fanni yakunlab, o'qituvchi umumiy xulosa chiqaradi. Fan davomida talabalar ma'lumotlar tuzilmalari va algoritmlarning asosiy tushunchalarini o'zlashtirdilar: algoritm murakkabligini baholash, massiv va ro'yxatlar, stek va navbat, rekursiya, daraxtlar, graflar, xesh jadvallar, qidirish va saralash. Eng muhimi, ular masalaga mos tuzilma va algoritmni asosli tanlash ko'nikmasini egalladilar. Bu bilimlar kutubxonachi-mutaxassisning zamonaviy axborot tizimlari bilan ishlashida, ma'lumotlarni tahlil qilishda va raqamli texnologiyalarni joriy etishda ishonchli poydevor bo'ladi.

Yakuniy tavsiyalar. Talabalarga o'rganishda davom etish tavsiya etiladi: algoritmlar bo'yicha bepul onlayn kurslar, dasturlash musobaqalari, ochiq kodli kutubxona dasturlari ustida ishlash. Ayniqsa, MARC formatlari, kutubxona integratsiyalashgan tizimlari, ma'lumotlar bazalari va qidiruv texnologiyalarini mustaqil o'rganish foydali. Algoritmik fikrlash kasbiy faoliyatning har bir sohasida muammolarni tizimli tahlil qilishga yordam beradi. O'qituvchi talabalarga muvaffaqiyat tilaydi va yakuniy nazorat shakli haqida eslatadi.

Yakuniy loyiha uchun qo'shimcha talablar ham belgilanadi. Dastur ma'lumotlarni faylga saqlay olishi va ishga tushganda fayldan yuklay olishi kerak. Buning uchun JSON formati qulay: kitoblar ro'yxati lug'atlar ko'rinishida yoziladi va o'qiladi. Foydalanuvchi interfeysi aniq va xatolarga chidamli bo'lishi lozim: noto'g'ri raqam yoki bo'sh qiymat kiritilganda dastur to'xtab qolmaydi. Har bir asosiy funksiya uchun kamida uchta avtomatik sinov yoziladi. Talabalar loyiha tavsifini, ya'ni qaysi tuzilma qayerda ishlatilgani va nima uchun, bir sahifali hujjatda bayon etadilar.

Loyiha ustida ishlash jarayonida guruh a'zolari vazifalarni taqsimlaydilar. Birinchi a'zo ma'lumotlar tuzilmalari va ularning sinflarini, ikkinchisi foydalanuvchi interfeysi va menyuni, uchinchisi sinovlar va hujjatlashtirishni mas'ul bo'ladi. Guruh a'zolari muntazam ravishda bir-birining ishini tekshiradilar va uyg'unlikni ta'minlaydilar. Bunday ish taqsimoti real dasturiy loyihalardagi jamoaviy ishni modellashtiradi va talabalarning hamkorlikdagi ishlash ko'nikmalarini mustahkamlaydi. Har bir a'zoning hissasi taqdimotda alohida ko'rsatiladi va baholanadi.

Kutubxona tizimini rivojlantirish bo'yicha g'oyalar muhokama qilinadi: o'quvchilarni ro'yxatdan o'tkazish, kitob berish va qaytarish muddatlarini hisoblash, kechikkan kitoblar uchun jarimani aniqlash, eng ko'p o'qiladigan kitoblar reytingini yuritish, kitoblarni mavzular daraxti bo'yicha tasniflash. Talabalar bu g'oyalardan birini tanlab, o'z loyihasiga qo'shimcha imkoniyat sifatida kiritishlari mumkin. Qo'shimcha imkoniyat uchun maxsus ball ajratiladi, bu esa talabalarni ijodiy yondashishga rag'batlantiradi va kasbiy yo'nalishga yaqinlashtiradi.

Fan yakunlangach, talabalar o'z o'quv yutuqlarini baholash uchun portfolio tayyorlashlari mumkin. Portfolioga har bir mavzu bo'yicha yozilgan eng yaxshi dastur, tajriba natijalari jadvali, yakuniy loyiha va qisqa shaxsiy xulosa kiritiladi. Bu to'plam talabaning algoritmik fikrlash va dasturlash qobiliyatini ko'rsatadi va kelgusida ish topishda yoki o'qishni davom ettirishda foydali bo'ladi. O'qituvchi portfoliolarni ko'rib chiqib, har bir talabaga individual tavsiyalar beradi.

Mashg'ulot yakunida talabalardan fan haqida fikr-mulohaza so'raladi: qaysi mavzular eng foydali va qiziqarli bo'ldi, qaysilari qiyin edi, amaliy mashg'ulotlar yetarlimi, qanday qo'shimcha mavzular kerak. Bu fikrlar fanni keyingi yillarda takomillashtirishda inobatga olinadi. Talabalar ham o'qituvchining ishini baholashdan manfaatdor, chunki ta'lim sifati ikki tomonlama aloqa asosida yaxshilanadi.

Mashg'ulot davomida talabalarga yana bir muhim tavsiya beriladi: dasturlashda yangi tuzilma yoki algoritm yozishdan oldin uning murakkabligini baholash odat bo'lishi kerak. Bu baholash bir necha daqiqa oladi, lekin dastur katta ma'lumotlarda sekin ishlab qolishining oldini oladi. Kurs davomida talabalar bu odatni mustahkamladilar va endi har bir yechim uchun «qancha vaqt va xotira kerak?» degan savolni o'zlariga berishlari lozim.
